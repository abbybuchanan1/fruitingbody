# Fruiting Body — Pass 3: artwork + pacing

This pass replaces structural artwork placeholders with web-optimized images exported from the current project PDFs supplied for the museum build.

## What to evaluate

Do **not** evaluate final colors/materials yet. Walk the museum and notice:

1. Image scale: which works feel too small / too dominant?
2. Pacing: where do you want more or less distance between works?
3. Grotto: does smaller-scale work create enough intimacy?
4. Red Room: do Red Thread, Shelter, and Unravel read as one continuous territory while remaining distinct projects?
5. Relative: does the paired/relational rhythm work?
6. Body of Water: does larger scale make the room feel expansive rather than merely long?
7. Membrane / Threshold: does near-viewport scale create useful compression?
8. Mobile: does the same sequence still feel intentional on a narrow screen?

## Important status notes

- Image order follows the current source PDF page order.
- Portfolio PDFs are treated as stronger sequence sources where available.
- Some rooms currently rely on index PDFs because no separate final portfolio source was supplied in this build packet. Treat those sequences as a pacing prototype, not a newly asserted final curatorial edit.
- Alt text in this pass is explicitly provisional. Final alt descriptions require a dedicated curatorial/accessibility pass; generic or automated descriptions should not silently become publication copy.
- Images are pre-exported to WebP so the prototype stays reasonably light. No image CMS or external media service has been introduced.
