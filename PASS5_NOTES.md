# Pass 5 — Visual Grammar Prototype

Scope intentionally limited to the Exterior and Vestibule.

## What this pass tests
- Exterior as a restrained, almost anonymous masonry facade.
- A single anachronistic carved-oak-like door as the entry cue.
- Exterior light/motion distinct from interior quiet.
- Vestibule as cool stone, dim but navigable, with water/skylight/moss implied using CSS only.
- Central Membrane arch remains primary without hiding alternate vestibule routes.
- Map + Index read as quiet annotations rather than conventional nav buttons.
- Motion is subtle and automatically removed under prefers-reduced-motion.

## Deliberately not included yet
- Photorealistic stone/brick textures.
- Video.
- Sound.
- 3D/WebGL.
- Circadian system.
- Room-by-room styling outside Exterior/Vestibule.

## Evaluation question
Does this feel materially and perceptually closer to entering a hidden institution, while remaining obviously usable and fast?
